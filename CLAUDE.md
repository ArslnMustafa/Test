## Code Generation Rules
- **No Empty Blocks:** Never generate blank, incomplete, or placeholder code blocks (e.g., no `// code goes here` or `...`).
- **Provide Full Code:** Write all modified or new functions, classes, and files completely. Do not omit any lines.
- **No Abridgement:** Never truncate code blocks. Do not use comments to represent existing code.

## Output and Description Rules
- **Concise Outputs:** Minimize or completely eliminate textual explanations outside the code block.
- **Direct Solution:** Do not write greetings, introductory phrases (e.g., "Here is your code:"), or summary conclusions.
- **Code Only:** Respond directly with the working code block. If a critical warning is necessary, provide it in a single, short sentence below the code.
